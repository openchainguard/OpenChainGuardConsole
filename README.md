# OpenChainGuard Client

Frontend console for managing OpenChainGuard AI-agent governance workflows.

## Scripts

- `npm run dev` - start Vite dev server
- `npm run build` - build production assets
- `npm run preview` - preview production build
- `npm run lint` - run ESLint
- `npm run test` - run Vitest tests

## Project Layout

- `src/app` - app bootstrap, providers, routes
- `src/components` - UI and shared components
- `src/pages` - page modules by feature
- `src/lib` - mocks and utilities
